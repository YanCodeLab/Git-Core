# Git Core

Repositório dedicado aos meus estudos de **Git e GitHub**, com foco no aprendizado de controle de versão e nas boas práticas utilizadas no desenvolvimento de software.

## 🎯 Objetivo

Desenvolver conhecimentos práticos em Git e GitHub, aprendendo a versionar projetos, gerenciar alterações e organizar o fluxo de trabalho de desenvolvimento.

## 📚 Aprendizado

Estudos realizados por meio de cursos da **Udemy**, com exercícios e práticas para consolidar os conhecimentos adquiridos.

## 🛠️ Ferramentas

- **Git** — controle de versão.
- **GitHub** — hospedagem e gerenciamento de repositórios.
